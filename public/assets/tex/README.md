# Unit surface skins

Tileable greyscale data maps for the 3D units (`src/client/proto3d/surface3d.ts`, triplanar in object space; which skin a
unit wears is chosen in `src/client/proto3d/skins.ts`). Generated by `scripts/gen-surface-textures.py`. The skin layouts
(plates, seams, rivets, hatches, vents, cast pits, welds, slabs, chitin, hex cells, pipes, grating, machinery, stencils, digits)
are procedural, original work under this repo's licence. Scratches, grime and mottling are derived from the CC0
photo-scanned maps below.

| file | contents |
|---|---|
| surf_detail.png | 15 x 512 px layers (scout, cast, slab, titan, air, rotor, arty, support, carapace, ceramic, brawler, stealth, grating, machinery, dullmetal): R,G = height slope (0.5 = flat), B = cavity / paint tone (0.75 = neutral) |
| surf_mask.png | the same 15 layers, one channel: per-skin special mask (camo, pits, slab frames, battle damage, soot, dust, role paint, sheen, accent panels + lights, gouges, oil) |
| hull_wear.jpg | 1024 px shared: R = chipped paint / scratches, G = grime + drip streaks, B = mottling (0.5 = neutral) |
| surf_marks.png | glyph atlas for big-unit markings: digits 0-9, kill tally, insignia |
