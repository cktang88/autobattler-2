# Unit surface-detail textures

Tileable 1024 px greyscale data maps used by the 3D units (`src/client/proto3d/surface3d.ts`, triplanar in object
space). Generated by `scripts/gen-surface-textures.py`. The plate/seam/rivet/hatch/vent/stencil layout is procedural
(original work, this repo's licence). Scratches, grime and mottling are derived from the CC0 photo-scanned maps below.

| file | channels |
|---|---|
| hull_detail.png | R,G = height slope d(h)/du, d(h)/dv (0.5 = flat) - B = cavity / paint tone (0.75 = neutral) |
| hull_wear.jpg | R = chipped paint / scratches - G = grime + drip streaks - B = mottling (0.5 = neutral) |
